

\# Customer Segmentation Project



\## 1. Project Overview

This project uses machine learning to segment customers based on their demographics, annual income, spending score, purchase frequency, and average order value.



\## 2. Objectives

\- Identify different customer groups.

\- Analyze customer purchasing behavior.

\- Understand customer spending patterns.

\- Support targeted marketing strategies.



\## 3. Technologies Used

\- Python

\- Pandas

\- NumPy

\- Matplotlib

\- Scikit-learn

\- KMeans Clustering



\## 4. Methodology

1\. Generate customer dataset.

2\. Perform data preprocessing.

3\. Standardize numerical features.

4\. Apply KMeans clustering.

5\. Analyze customer segments.

6\. Visualize the results.



\## 5. Results

The KMeans algorithm identified four customer segments.



The results help businesses understand customer behavior and develop targeted marketing strategies.



\## 6. Output Files

\- customer\_data.csv

\- segmented\_customers.csv

\- segment\_summary.csv

\- customer\_segments.png

\- segment\_analysis.png



\## 7. Conclusion

Customer segmentation helps businesses understand different customer groups, improve marketing strategies, and make better business decisions.
